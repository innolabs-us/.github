# InnoLabs

**Incubation lab for [Naatu Paakam](https://github.com/naatu-paakam).**

InnoLabs is where ideas are built, validated, and stress-tested — before graduating to the Naatu Paakam product family. If an MVP proves market fit, it moves to production. If it doesn't, we document why and move on.
